▶️ 실행 방법
🪟 Window
받은 zip 파일을 오른쪽 클릭 → [압축 풀기] 합니다.
압축을 푼 폴더 안의 In the Black Shadow.exe 를 더블클릭합니다.
파란색 "Windows의 PC 보호" 창이 뜨면 → [추가 정보] → [실행] 을 누릅니다.

⚠️ zip 안에서 바로 실행하면 작동하지 않아요. 꼭 압축을 먼저 풀어 주세요.

🍎 Mac
받은 zip 파일을 더블클릭해서 압축을 풀고, In the Black Shadow 앱을 [응용 프로그램] 폴더로 옮깁니다.
앱을 오른쪽 클릭 → [열기] 를 누릅니다. 막히면 [시스템 설정 → 개인정보 보호 및 보안] 아래쪽의 [그래도 열기] 를 누릅니다.
"손상되었기 때문에 열 수 없습니다" 가 뜨거나 앱이 열리지 않으면, [터미널] 앱을 열고 아래 두 줄을 차례로 붙여 넣은 뒤 다시 실행합니다.
xattr -cr "/Applications/In the Black Shadow.app"
chmod +x "/Applications/In the Black Shadow.app/Contents/MacOS/In the Black Shadow"
